Theory: Ingestion & Text Preprocessing Critical Theory

Text Cleaning & Normalization

  • Case Folding: Converting all characters to lowercase prevents the model from treating "Returns" and "returns" as distinct tokens.
  • Null Handling: Empty reviews or non-textual input fields cause crashes in vectorizers. They must be isolated and pruned.
  • Noise Removal: Pruning HTML markup tags, excessive punctuation, and formatting symbols.

The Imbalanced Class Danger

Real-world support queues are heavily skewed. If 90% of requests are spam, classifiers learn to ignore minority classes (like refunds).

Imbalance Solution: Stratified splitting guarantees that train and test distributions represent equal proportions of every class label.

MODULE 2

The Text Representation Battle: TF-IDF vs. Hugging Face

How do computers analyze human language? We compare classical statistical sparse matrices (TF-IDF) against modern dense deep learning semantic coordinates from Hugging Face Hub.

Sarveshwar Academy × Knowledge Institute of Technology Module 2 | Text Representations

Sparse Vector (TF-IDF) vs. Dense Semantic Embeddings Feature Design

Sparse Matrix (TF-IDF)

Represents text by tracking exact word occurrences across documents. Dimensionality increases with vocabulary size.

$\text{TF-IDF}(t, d) = \text{TF}(t, d) \times \text{IDF}(t)$

Failure: Sentence "A" and "B" sharing zero words result in 0.00 similarity, even if they mean the exact same thing!

Dense Vector (HF Embeddings)

Encodes semantic meaning into fixed-size real numbers (e.g., 384 dimensions) using transformer models.

$\text{Embedding}(S) \in \mathbb{R}^{384 \text{ dimensions}}$

Strength: "Late delivery" and "Package didn't arrive" map to close coordinates, returning high cosine similarity.

Sarveshwar Academy × Knowledge Institute of Technology Module 2 | Text Representations

Visualizing TF-IDF Sparse Vector Representation Concept Visualization

Sparse Words Matrix

TF-IDF forms a sparse matrix where each row is a document and each column represents a vocabulary word. Cells display calculated statistics.

  • Zero Overlap Problem: Missing direct keyword links drops document correlation to 0.
  • Memory Bloat: Column dimensions expand rapidly for large corpora.
Sarveshwar Academy × Knowledge Institute of Technology Module 2 | Text Representations

Visualizing Hugging Face Dense Embeddings Concept Visualization

Semantic Vector Space

Dense embeddings map sentences to coordinates. Meaning is encoded as coordinate location. Synonyms and related terms lie close together.

  • Fixed Dimensions: Uniform vector lengths (like 384 numbers).
  • Continuous space: Resolves semantic closeness mathematically.

Theory: The Hugging Face Hub Ecosystem Critical Theory

Hugging Face Hub acts as the "GitHub of Machine Learning", storing hundreds of thousands of pre-trained models called checkpoints.

  • Model Cards: Readme sheets explaining what data the model was trained on, metrics, and limitations.
  • Tokenizers: Convert raw strings to integer sequences (tokens) that match the model's vocabulary file.
  • Sentence Transformers: Fine-tuned versions of BERT/RoBERTa using contrastive learning, forcing similar sentences to lie close in vector space.

Local Cache Pipeline

1. Fetch Checkpoint

Downloads config.json and safetensors weights from HF Hub.

2. Run Local Tokenization

Splits text into subword IDs using Rust-backed tokenizers.

3. Pooling & L2 Normalization

Averages token states into a single 384-dimensional unit vector.

Supervised Boundaries: Support Vector Machines (SVM) Algorithm Logic

How does a computer separate customer reviews? By fitting hyperplanes in high-dimensional vector spaces.

  • Maximum Margin: SVM finds the hyperplane that maximizes distance (margin) between the nearest data points of different classes (support vectors).
  • Linear Kernel: Excellent for text embeddings because high-dimensional spaces (like 384 dimensions) are almost always linearly separable.
  • Efficiency: Fast to train, highly reliable, and doesn't require millions of parameters.

○ ○ ○

[ Class B: Refunds ]

Why Simple Accuracy is a Trap in Real Projects Evaluation Metrics

The Class Imbalance Problem

If 95% of incoming tickets are normal spam, and only 5% are billing issues, a dumb model that predicts "spam" for everything has 95% accuracy but is 100% useless to your finance team.

We must evaluate using metrics that account for class distributions.

Metric Formula What it measures
Precision TP / (TP + FP) Out of predicted positive, how many were right? (Avoid False Alarms)
Recall TP / (TP + FN) Out of actual positive, how many did we find? (Avoid Misses)
F1-Score Harmonic Mean Balanced summary of both Precision and Recall.
Sarveshwar Academy × Knowledge Institute of Technology Module 3 | Classification

Precision, Recall & F1-Score: A Numerical Example Metric Walkthrough

The Scenario (100 Support Tickets)

• Actual: 10 Refund Requests (Positive), 90 general inquiries (Negative).
• Model Prediction: Flags 8 tickets as Refunds. Out of these, 6 are correct (TP=6) and 2 are general inquiries (FP=2). The model missed 4 refunds (FN=4).

TP = 6 | FP = 2 | FN = 4 | TN = 88
  • Precision: $ rac{TP}{TP + FP} = rac{6}{6 + 2} = rac{6}{8} = 75.0\%$
    Meaning: 75% of tagged refund tickets were actually refunds.
  • Recall: $ rac{TP}{TP + FN} = rac{6}{6 + 4} = rac{6}{10} = 60.0\%$
    Meaning: The system caught 60% of all refunds in the queue.
  • F1-Score: $2 imes rac{ ext{Precision} imes ext{Recall}}{ ext{Precision} + ext{Recall}} = 2 imes rac{0.75 imes 0.60}{0.75 + 0.60} pprox 66.7\%$
    Meaning: A single score balancing precision and recall.

K-Means & Outliers in Semantic Vector Spaces Algorithm Logic

K-Means Topic Discovery

Clusters coordinates by minimizing Euclidean distances inside clusters. We group comments into K = 4 groups automatically based on embeddings.

Anomaly / Outlier Detection

Compute distance: $d_i = \| X_i - \mu_{\text{centroid}} \|$. Data points far away from all cluster centroids represent unusual feedback, potential fraud, or formatting errors.

Distance-based Anomaly

Centroid Cluster ($\mu$)
● ● ● ●
Normal ticket distance: low ($d < 0.2$)
✖ [Outlier / Anomaly]
Extreme distance: high ($d > 0.8$)

Theory: Local Zero-Shot Prompting Architecture Critical Theory

How does zero-shot LLM routing differ from SVM? It bypasses training data completely by leveraging massive pre-trained semantic weights.

  • In-Context Rules: We insert system instructions, class labels, and prompt instructions directly inside the context window.
  • JSON Enforcement: Passing structural schemas and configuring API return formats to enforce strict JSON syntax outputs.

JSON Output Schema

{
  "category": "Refunds",
  "reason": "The customer requests money return."
}
Sarveshwar Academy × Knowledge Institute of Technology Module 5 | Model Comparison

Running Local Zero-Shot Prompts with Ollama Ollama Integration

Why Local LLM?

Local LLMs (e.g. Phi-3 or Llama-3 running on Ollama) provide zero-data startup capabilities, privacy compliance (no data leaves the machine), and zero-cost token inference.

JSON Mode Extraction

Instructing LLMs to return strict JSON strings ensures downstream code can parse outputs reliably without human regex parsing.

Python Ollama Request

import ollama

response = ollama.generate(
    model='phi3',
    prompt=prompt,
    format='json'  # Request structured JSON
)
output = json.loads(response['response'])
print(output['category'])

Structure for Real-World AI Project Kickstart Best Practices

Faculties can immediately adopt this template for student projects or thesis research work. It enforces modern engineering practices:

  • src/ Folder: Encapsulates isolated, modular python components instead of giant script dumps.
